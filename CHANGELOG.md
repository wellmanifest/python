# Changelog

All notable changes to the Wellmanifest Python Standard will be documented in this file.

## [0.1.0] - 2026-09-19

### Added
- Initial specification of Wellmanifest Python Standard.
- Dual-runtime isolation resolution guide (system venv vs active repo checkouts).
- Shell execution and binary resolution guidelines (`~/.local/bin`, `hash -r`, `~/.profile`).
- Multi-identity and rate limit resilience patterns for GitHub and PyPI.
- `goal -a` workflow specification for automated publishing and dependency propagation.
- Troubleshooting matrix for common CLI, venv, and credential problems.
